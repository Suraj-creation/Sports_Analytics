# Test 2 repair: final validation and limitations

The [consolidated report](../../reports/test_02_consolidated_v1.md) supersedes
pending-run language in earlier application-time receipts. Those original
receipts and failed diagnostic attempts remain preserved without alteration.

The production repair adds anatomical-ambiguity admission at the badminton
engine ingress. It creates semantic copies, withholds selected current geometric
racket ellipses supported by current facial landmarks, and emits reviewable
abstention evidence. Original perception, raw racket geometry, checkpoints,
numerical profile and annotations remain unchanged. A withheld cue is not a
reviewed physical negative, and remaining candidates are not certified rackets.

Validation completed:

- 2,515 main tests and 689 research tests passed; lint passed. The new portable
  admission suite has 25 cases, including freshness, ownership, coordinate
  transformation, cross-person anatomy and preservation controls.
- Both Test 2 arms completed fresh GPU inference over all 29,296 frames. The
  post-fix run's strict own-cache replay reproduces all 29,296 semantic steps.
- Independent cache comparison found all 29,296 fresh raw observations equal
  to baseline. Each of 4,239 abstentions maps uniquely to preserved raw evidence.
- All three reference F1 values remain unchanged. Coarse mean IoU declines
  0.833215 to 0.830665, while generated timing IoU increases 0.848135 to 0.849311.
  The report includes every boundary and duration change, miss and extra interval.
- Test 1's six reference metric sets are unchanged across the complete
  17,268-frame fixed-perception regression, with all 287 observed nonterminal
  scheduling drivers equal. This is not a fresh Test 1 neural run. Contact,
  provisional attribution and highlight changes remain explicitly documented.
- Complete annotation and baseline preservation receipts are present. Final
  [retention manifests](../retention/) independently verify retained artifacts
  before the exact owned download can be removed.

Unresolved issues remain measured or diagnosed: background-player track
replacement, propagated-box errors, shuttle disappearance/reacquisition and
rally splitting, missed edit acquisition, nonfacial racket distractors, absent
appearance-model artifact, and unresolved athlete/outcome/score binding. Broad
threshold tuning, guessed labels and checkpoint substitution were not supported
by comparative evidence. Missing independent boxes, IDs, joints, contacts and
outcome bindings leave ten physical-accuracy families unavailable. The repair
improves evidence handling; it does not establish uniform sporting accuracy.
