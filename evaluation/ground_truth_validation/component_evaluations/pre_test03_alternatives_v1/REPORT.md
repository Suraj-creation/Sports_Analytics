# Remaining Test1–2 weaknesses: controlled alternatives, not adopted replacements

Checked2026-11-12, documentation/metadata only. No NN, checkpoint, dataset or
video download; no source/profile/annotation change; no Test3 access. Small
upstream documentation/licence/source files were archived without execution.
This report does not pre-empt the running candidate's fresh regression results.

The most justified next trial is **a source-bound shuttle visibility/branch
experiment**, followed by object-specific racket evidence and optional existing
appearance association. No reviewed evidence establishes that a new backbone
improves our pipeline. Upstream TrackNetV3, WASB and RacketVision heads still
match the previous audited commits. Their README scores are not comparable
Test1–2, end-to-end or doubles results.

## Diagnosis determines the trial

The new [perception diagnosis](../pre_test03_perception_v1/REPORT.md) materially
updates the older outlier review: at Test2 frame6492, the **existing RF-DETR
already proposes both athletes**, including the omitted near athlete at0.939.
At11346 both proposals also exist; the original adapter returned neither on
that detector tick. Birth activation and court-authority integration are the
demonstrated defects. A different person backbone is not the supported remedy.
The355/25521 outliers are stale carry after source edits, not proven ordinary
Kalman drift. The candidate's ongoing full evaluation must establish remaining
errors after those repairs.

For shuttle G69,22 raw-missing frames precede competing reacquisition branches;
some frames retain weak peaks and others none. Source review does not certify
which later branch is the physical shuttle. A high-clear outside the image is
not recoverable image detection. Separate **visible-but-missed**, **out of view**,
**occluded/blurred** and **unresolved** before selecting a method. The
[temporal contract repair](../pre_test03_temporal_v1/REPORT.md) preserves estimated
context, not observed positions or physical contacts; it is not a new detector.

## Existing exposed controls and new labels needed

Use the existing **exposed** sparse Shot/SS22/India/Denmark and continuous
DShuttleNet doubles experiments as regression controls, not newly blind evidence.
Retain their source video/hash, FPS, all original partitions/classes/actor labels,
crop translation and unknown/draft flags. The converter explicitly requires
`canonical_frame = CSV.frame_num + declared_offset`; old India/Denmark−1/−3
pre-crop bindings are not offsets to transfer to Test1/2. Keep fixed±3/±6 frame
reports, native12 and the prior frozenD9 projection separate. The older25FPS
AI-draft doubles box excerpt is not the3600-frame publisher-anchor recording.

Existing results already constrain proposals: the exposed doubles run had
21TP/14FP/24FN at±3, only1 correctly classified matched anchor and27/35 unknown
classes. Bracketed geometry added2 correct **and4 wrong** matched labels. The
older0044 BST shadow did not improve repaired-rules macro-F1 (.05500 versus
.05934) and assigned known classes to16/19 false contacts versus5/19 for rules.
These are historical protocol-specific measurements, not results from the
running candidate. The reserved recording0046 remains reserved; it was not read
or retuned here. [Doubles evidence](../../../../research/DOUBLES_VALIDATION_REPORT.md),
[BST frozen comparison](../../../../docs/testing/bst-adapter-20261029.md).

Before claiming a physical gain, freeze a separate reviewed set and whole-match
held-out split with:

- Shuttle visibility and pixel location/uncertainty, out-of-view/occlusion,
  top-image exits/returns, weak serve launches, static markings/spare shuttles,
  adjacent-court objects and competing reacquisition branches.
- Racket boxes/five-point or agreed geometry labels, visible/occluded/absent
  status, head/jersey/banner negatives and all competing owners. Contacts need
  exhaustive times or uncertainty intervals and negative spans, not only existing
  machine candidate reviews.
- Stable physical participant/team IDs, visibility/crossings/cuts/end changes,
  exhaustive target-person boxes and current-versus-carried stamps; a detection
  slot or image half is not an athlete name.
- Contact-linked native stroke classes, genuine unknowns, hitter roles and
  adjudicated score/outcome links where relevant. Preserve sparse annotation
  coverage and all unmatched predictions rather than declaring unlabeled time
  negative or predictions ground truth.

Predeclare identical matching/localization tolerances, per-class support and
confusion, contact false positives per minute, missed contacts, abstention,
conditional class/hitter accuracy **and end-to-end recovery**, rally boundaries,
and actual hardware latency/resources. Report singles and four-player doubles
separately. Test1/2 and previously inspected external footage remain development
material. A future model trial must improve reviewed held-out evidence with
these denominators; fewer unknowns, smoother paths or better matched IoU alone
are insufficient.
