# Completed Test2 neural run: structural audit compatibility proposal

The original full-neural worker and executor completed29,296 canonical frames. The subsequent technical audit failed because `audit_frames()` rejects every content-epoch increment whose raw scene hypothesis is false. The producer's newer source-bound contract deliberately allows a different case: V4 relative image acquisitions plus a positively corroborated V3 court/camera/layout decision. A raw weak acquisition remains distinct from a strong scene hypothesis. Original worker, parent, cache catalogue and failed outer orchestration must remain unchanged.

This proposal changes structural postprocessing compatibility only. It does not change prediction bytes, source inference, interval matching, IoU arithmetic, thresholds, reference eligibility, point pairing, confidence handling, labels or reported accuracy. In particular, no claim that all seven original methods changed is appropriate: original methods remain byte-identical; a separately versioned structural audit is needed because one original guard lacks the producer's new proof family.

## Verified public boundaries

The frozen native `research.pipeline_repair_run_analysis.load_analysis_input(run, None)` already validates a genuine fresh completed worker/executor/session/frontier/source/proxy/catalogue. It returns explicit paths, hashes, media, profile and worker metadata. Its underlying `production_external_semantic_replay.load_finished_input()` is likewise a public strict completion loader. Neither depends on a successful outer report.

The frozen native `BadmintonSession.decode_perception(receiver, payload, diagnostic=True)` validates the actual bounded cache format without performing inference or changing perception state. The existing semantic replay uses a `SimpleNamespace` receiver carrying the packet's reference and policy. Native validation binds raw/decision versions, detector identity, frame dimensions, witness parameters and recomputed cohort arithmetic, mandatory decisions, prior/current source camera transforms, calibrated court polygon/reference fingerprint and confirmed source chunk-start format. It rejects new V4/V3 evidence downgraded to old codec headers. A separate cross-catalogue audit must additionally bind serialized previous camera to the actual adjacent previous packet, since within-packet decoder validation cannot establish a preceding packet's camera by itself.

The original `analyse()` orchestrator hardwires `load_analysis_input()` and `audit_frames()`; it has no callback or producer-root parameter. Patching imported `ROOT`, rewriting metadata or replacing its global functions would misrepresent the executed source and must be avoided.

## Proposed explicit producer/tool separation

Add a **new** postprocessing adapter outside the frozen native checkout. Its CLI accepts the recorded `--producer-root`, current `--tool-root`, run and exclusive new report directory. Execute a native bootstrap with candidate2418 PYTHONPATH. That bootstrap imports and verifies actual native completion/decoder modules and their real ROOT, then imports the new tool module by its explicit absolute path under a distinct module name. The new module must not alter sys.path or a native module's ROOT, and must receive the native API as an explicit dependency. Record both roots, both source/hash populations and the exact adapter source.

The adapter first calls the unchanged native loader, rehashes the recorded producer plan source files and completed input catalogue, then diagnostically decodes every retained packet through the actual native decoder. It calls a separately named/versioned structural frame audit. All existing numeric/event/resource/reference helpers are invoked unchanged from their native modules. If reproducing the original report-building sequence is necessary, preserve its source and a reviewable diff showing only explicit dependency calls and the additional compatibility provenance; do not modify the original producer script.

No NN worker is started. Re-run only technical analysis, supported reference evaluations, downstream exports, semantic parity, visual evidence and matrix/report publication on the original completed predictions/caches. Preserve the failed analysis log/result and outer failure receipt; issue a new postprocessing completion receipt explicitly linked to them rather than changing their statuses. Child commands, source/model/profile guards and artifact hashes remain mandatory.

## Version-aware epoch rule

Preserve original strong and legacy checks exactly. A raw-false epoch increment is accepted only when all of the following hold after actual native cache decoding:

- Raw evidence is `foreground-scene-hypothesis:v4` with false strong hypothesis.
- Decision is `detector-layout-scene-decision:v3`, positive `barrier`, with raw_hypothesis false and matching typed raw/decision output from the native decoder.
- Actual content epoch increases at that source frame.
- Native source court/camera/format/model proofs pass, including actual adjacent-camera binding across chunk boundaries.

A missing, unknown or no-barrier decision cannot authorize a weak reset. Legacy header downgrade, forged raw cohort, court polygon, relative transform or unconfirmed format cannot authorize it. A positive weak barrier without an actual epoch increment must also fail. No numeric evaluation threshold is introduced by this contract.
