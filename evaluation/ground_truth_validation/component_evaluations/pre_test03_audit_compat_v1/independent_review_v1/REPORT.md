## Native imports and validation boundary

`load_native_interfaces()` requires the actual native analysis module file, its actual `ROOT`, and the native decoder file under the explicit producer checkout. Numerical helper origins must also lie under that checkout. The corrected producer guard binds the original executor's worker command to the producer's `production_external_stress.py`, requires that worker in the recorded source population, rejects foreign source paths and rehashes every recorded source file. `plan.root` is correctly retained as the external protocol workspace rather than mistaken for a source checkout. No native global or `ROOT` is reassigned.

Every cache packet is passed through the actual native diagnostic decoder. That decoder validates the declared codec/raw/decision family, source-frame/epoch/model identity, recomputed cohort and witness arithmetic, mandatory decision, calibrated court-reference/polygon binding, image shape and confirmed pre-acquisition format. The separate audit additionally binds previous-camera claims to the actual immediately preceding cached frame across packet boundaries; missing/invalid previous source context or inconsistent transforms fails. Native strict completion/catalogue hashes remain the trust boundary for the original packet bytes.

A raw-false epoch increase requires positive typed V4/V3 evidence, an actual epoch increment, current source court/camera proof and confirmed singles/doubles participant count. Missing, unknown or no-barrier decisions cannot authorize it. A positive weak decision without an epoch increment also fails. Legacy strong unknown fallback retains its original behavior. The audit retains false raw-hypothesis values in counters/CSV rather than fabricating a strong hypothesis.

These are consistency and provenance checks. They do not prove the detector saw a physical athlete, the inferred court/format is correct, or a reset is a real edit. Coherently fabricated new recordings are outside an audit of the already hash-bound original producer artifacts; diagnostic mutations are not visual truth.
