# Event and score defect ledger

Baseline `cc73688`; 3 November 2026. P1 = score correctness/publication risk,
P2 = bounded projection/artifact risk. Status entries describe observed evidence,
not an assertion of real-world perception accuracy. Final validation is tracked in
[the report](event-score-integrity-20261103.md).

All listed regression files pass in the final integrated validation: 1,356 backend
tests, 149 frontend tests and the real browser score synchronization spec. See the
report for runtime, lint warnings and limitations; these counts are not accuracy metrics.
