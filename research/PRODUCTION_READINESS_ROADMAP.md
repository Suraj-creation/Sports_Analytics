No default profile, deployment, service, accepted media asset, label, matching rule or historical evidence is promoted/changed to improve a score. A future promotion needs repeat inference of the exact candidate and independently reviewed, previously unseen matches. Quality/balanced/live modes need measured accuracy/resource/latency limits; profile names alone do not establish those modes.

The next reviewed annotation package should prioritize a small representative set: amateur singles and four-person doubles, multiple cameras/courts/light, similar clothing, occlusion, static markings, real floor shuttles, edits, noisy inputs and variable timestamps. Record unknown/out-of-view evidence and adjudication, never pseudo-label it as independent truth. Use [PRODUCTION_READINESS_ANNOTATION_PROTOCOL.md](PRODUCTION_READINESS_ANNOTATION_PROTOCOL.md) and the existing unchanged rally/shot/tracking/participant evaluators.

## Final priority after this iteration

The implementation/evidence iteration is complete; production acceptance is not. First address low contact/shot reliability and short/missing-evidence boundaries with independently reviewed source labels, preserving explicit abstention. Test7 adds useful independent recording mechanisms and a real floor-shuttle negative control, but the recordings are previously exposed and source bindings remain draft/coarse. No global duration, merge gap, timing offset or impulse replacement was accepted.

Retain the unchanged evaluator and prospective split/annotation protocols. Repeat the exact chosen neural profile, evaluate a new match-disjoint reviewed set, measure actual deployment hardware/live behavior, and review old-HLS migration/routing before any default/deployment promotion. Current concrete code and passing software tests are recorded in the final report; they do not fill these evidence gaps.
